# Fanera Brains — конструктор коробок

Параметрический конструктор изделий из листовой фанеры. Геометрическое ядро не зависит от интерфейса: размеры, соединения, панели и SVG считаются в миллиметрах и покрыты тестами.

Это не развёртка картонной коробки. Панели — отдельные детали, линий сгиба нет. Первое соединение — паз + шип.

## Слои

```
параметры
  → Dimension Engine
  → Joint Engine
  → Geometry Engine
  → панели
  → Layout Engine
  → SVG
```

3D и DXF намеренно не входят в этот этап. Поза каждой панели уже лежит в общей модели, чтобы будущий просмотр Three.js не строил вторую геометрию.

| Пакет | Ответственность |
| --- | --- |
| `packages/core` | Модель, размеры, соединения, контуры, лист, гравировка, SVG |
| `apps/web` | Форма параметров, просмотр SVG, зум, выбор панели, загрузка логотипа |

Интерфейс вызывает `buildProduct()` и не пересчитывает контуры сам.

## Конструкция `closed-box`

Допущения записаны в `packages/core/src/model/assumptions.ts` и показаны в интерфейсе.

- Перед и зад равны внешним ширине и высоте.
- Лево и право стоят между ними: длина по глубине равна внешней глубине минус две толщины.
- Дно и крышка вложены между стенками.
- Шипы на вложенных панелях, пазы — краевые вырезы на принимающих.
- Число толщин между внутренним и внешним размером задаёт описание конструкции (`2 / 2 / 2` для закрытой коробки), а не формула «всегда + 2 × толщина».
- Керф сдвигает только траекторию реза. Clearance увеличивает только паз.
- `tabWidth`, `edgeMargin` и `minGap` — входные параметры. Стартовые значения в интерфейсе помечены как предложение, не как цеховая норма.

Внешний код Boxes.py, CardBoxGen, Joinery и остальных референсов в репозиторий не копировался.

## Команды

```bash
npm install
npm test
npm run dev
```

`npm test` проверяет внешние и внутренние размеры, толщины 3/4/6 мм, керф, clearance, паз + шип, панели, некорректные и слишком маленькие коробки, большую коробку, SVG, перенос, поворот и масштаб логотипа.
