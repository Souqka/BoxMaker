# Fanera Brains — конструктор коробок

Статическое веб-приложение для параметрических коробок из листовой фанеры. Backend нет. Страницу можно открыть локально и позже выложить на GitHub Pages. Геометрическое ядро — обычные ES-модули, их можно перенести на основной сайт без переписывания.

Это не конструктор картонной упаковки: у деталей нет линий сгиба. Первое соединение — паз + шип. На этом шаге готова только архитектура, не производственная геометрия.

## Статус

Сейчас работает путь:

параметры → Dimension Engine → Joint Engine → панели → раскладка → SVG

Dimension Engine и Joint Engine — заглушки с постоянным API. Следующий отдельный шаг — настоящий расчёт внутренних и внешних размеров. Шипы, интерактивный редактор, 3D и DXF сюда не входят.

## Архитектура

Модель одна. SVG и будущий Three.js получают её снаружи и не строят вторую геометрию.

```
UI
→ BoxModel
→ Dimension Engine
→ Joint Engine
→ Panel Model
→ Layout
→ SVG Renderer
```

| Модуль | Роль |
| --- | --- |
| `src/models/BoxModel.js` | Ширина, глубина, высота, режим external/internal, материал, тип конструкции |
| `src/models/Material.js` | Толщина, керф, clearance. Движок не ограничивает толщину списком 3/4/6 |
| `src/models/Logo.js` | Гравировка в миллиметрах выбранной панели. Форматы: svg, png, jpg |
| `src/validation.js` | Проверка положительных размеров и неотрицательных керфа и clearance |
| `src/geometry/dimensions.js` | `resolveDimensions()`. Второй контур спрашивает у соединения |
| `src/geometry/joints.js` | `createJoint()`. Сейчас только `tab-slot` |
| `src/geometry/panels.js` | Панель: контур, пазы, шипы, вырезы, гравировка |
| `src/geometry/box.js` | Сборка геометрии из модели |
| `src/geometry/layout.js` | Раскладка деталей на листе, миллиметры |
| `src/renderers/svg.js` | Слои cut, engraving, construction, dimension |
| `src/editor/` | Заготовки выбора, переноса и гравировки. В страницу не подключены |

Все расчёты ядра идут в миллиметрах. Пиксели есть только в CSS.

Внутренний и внешний размер — разные режимы ввода. Формула «внутренний = внешний − 2 × толщина» в ядро не зашита. Пока `tab-slot` возвращает введённый размер для обоих контуров и помечает результат как предварительный. Когда появится раскладка панелей, меняется `projectOppositeEnvelope` у соединения. Интерфейс и `resolveDimensions()` остаются.

Прямоугольники на листе — временный вид внешних габаритов, не геометрия паза и шипа. Пазы и шипы в модели есть, но списки пустые.

## Запуск локально

Из папки приложения:

```bash
cd fanera-box-constructor
python3 -m http.server 4173
```

Открыть http://127.0.0.1:4173/

Модули не работают по `file://`. Нужен любой статический сервер.

Тесты, без дополнительных библиотек:

```bash
cd fanera-box-constructor
node --test tests/*.test.js
```

Из корня репозитория: `npm test`.

## GitHub Pages

Приложение не вызывает API GitHub Pages.

Классические Pages публикуют корень репозитория или папку `/docs`. Эта страница лежит в `fanera-box-constructor`. Чтобы выложить именно её, достаточно GitHub Action, который загружает эту папку как артефакт Pages. Логика конструктора от способа публикации не зависит.
