# Fanera Brains — конструктор коробок

Статическое веб-приложение для параметрических коробок из листовой фанеры. Backend нет. Страницу можно открыть локально и позже выложить на GitHub Pages. Геометрическое ядро — обычные ES-модули, их можно перенести на основной сайт без переписывания.

Это не конструктор картонной упаковки: у деталей нет линий сгиба. Первое соединение — паз + шип. Размеры уже считаются. Контуры пазов и шипов ещё нет.

## Статус

Сейчас работает путь:

параметры → Dimension Engine → Joint Engine → панели → раскладка → SVG

Dimension Engine принимает внешние или внутренние размеры и возвращает оба контура. Сдвиг между ними сообщает Joint Engine. Для закрытого паза + шипа это две стенки на каждой оси. Шипы, настоящие контуры, интерактивный редактор, 3D и DXF сюда не входят.

## Архитектура

Модель одна. SVG и будущий Three.js получают её снаружи и не строят вторую геометрию.

```
UI
→ BoxModel
→ Dimension Engine
→ Joint Engine
→ Panel Model
→ Layout
→ SVG Renderer
```

| Модуль | Роль |
| --- | --- |
| `src/models/BoxModel.js` | Ширина, глубина, высота, режим external/internal, материал, тип конструкции |
| `src/models/Material.js` | Толщина, керф, clearance. Движок не ограничивает толщину списком 3/4/6 |
| `src/models/Logo.js` | Гравировка в миллиметрах выбранной панели. Форматы: svg, png, jpg |
| `src/validation.js` | Проверка ввода. Минимум 10 мм считается в одном месте, внутри `normalizeDimensions` |
| `src/geometry/dimensions.js` | `normalizeDimensions()` и `resolveDimensions()`. Второй контур берётся из поправки соединения |
| `src/geometry/joints.js` | `createJoint()`. Сейчас только `tab-slot`, через `getDimensionAdjustment()` |
| `src/geometry/panels.js` | Геометрия детали: контур, пазы, шипы, вырезы, гравировка. Идентификаторы шести панелей |
| `src/geometry/panelLimits.js` | Лимит одной детали 700 × 500 мм. Вызывается по размеру панели, не по габариту коробки |
| `src/geometry/box.js` | Сборка объекта, который получит Geometry Engine |
| `src/geometry/layout.js` | Где деталь лежит на листе: `panelId`, `x`, `y`, `rotation`, миллиметры |
| `src/renderers/svg.js` | Слои cut, engraving, construction, dimension |
| `src/editor/` | Заготовки выбора, переноса и гравировки. В страницу не подключены |

Все расчёты ядра идут в миллиметрах. Пиксели есть только в CSS. Промежуточные размеры не округляются: округление для показа живёт в странице.

Прямоугольники на листе — временный вид внешних граней, не геометрия паза и шипа. Пазы и шипы в модели есть, но списки пустые.

Каждая сторона коробки не меньше 10 мм. Код ошибки один: `MIN_DIMENSION`. Толщина по-прежнему любое положительное число.

Одна готовая деталь не должна быть больше 700 × 500 мм. Поворот на листе не меняет этот прямоугольник: 500 × 700 тоже помещается. Проверка — `validatePanelSize(panel)`. Она смотрит на ширину и высоту детали. Пока контуры не построены, сборка коробки её не вызывает: заготовки граней ещё не готовые детали. Лимит передаётся дальше в `geometry.panelLimits`.

## Layout

Геометрия детали и её место на листе разделены. Geometry описывает форму. Layout описывает положение.

Стандартная схема — логический вид шести панелей, не производственный порядок шипов:

```
              lid
               |
            side-1
               |
     front — bottom — back
               |
            side-2
```

Идентификаторы: `lid`, `side-1`, `front`, `bottom`, `back`, `side-2`.

Позиция в миллиметрах:

```js
{ panelId: "bottom", x: 0, y: 0, rotation: 0 }
```

`x` и `y` — левый нижний угол до поворота, ось Y вверх. `rotation` — градусы против часовой стрелки. SVG только читает эти поля и переворачивает Y. Координаты ряда в рендерере не зашиты. Позже на ту же модель можно поставить компактную раскладку, nesting или ручной перенос.

## Dimension System

Внешние размеры — габарит готовой коробки снаружи. Внутренние размеры — полезная полость внутри стенок. Пользователь задаёт один из этих наборов и `dimensionMode`: `"external"` или `"internal"`. `resolveDimensions()` возвращает оба.

Система координат:

- X = width
- Y = depth
- Z = height

Значения — обычные числа в миллиметрах: `{ width: 300, depth: 200, height: 100 }`. В ядре нет строк `"300mm"` и нет пикселей.

Нельзя зашить в Dimension Engine формулу `internal = external − 2 × thickness`. Реальная полость зависит от толщины, от того, какие панели закрывают ось, от соединения и от будущей схемы сборки. Движок размеров только прибавляет или вычитает поправку, которую отдаёт соединение:

```js
joint.getDimensionAdjustment(material)
// { width, depth, height } в миллиметрах
```

Joint Engine для `tab-slot` описывает закрытый корпус: слева и справа, спереди и сзади, дно и крышка. На каждой оси поправка равна числу этих панелей, умноженному на `material.thickness`. Другое соединение — finger-joint, dovetail, butt, custom — подключается своим `getDimensionAdjustment`, без ветки `if` внутри Dimension Engine и без смены UI.

Толщина — любое положительное число. 3, 4 и 6 мм в форме — только пресеты. Керф и clearance остаются на материале. На номинальный габарит они сейчас не влияют и не подменяются производственными коэффициентами.

```js
const resolved = resolveDimensions({
  dimensions: { width: 300, depth: 200, height: 100 },
  dimensionMode: "external",
  material: { thickness: 4, kerf: 0.15, clearance: 0.1 },
  joint: { type: "tab-slot" },
});
```

Следующий Geometry Engine получает уже собранный объект, а не поля формы:

1. `dimensions.external` и `dimensions.internal`
2. `material.thickness`, `material.kerf`, `material.clearance`
3. `construction`
4. `panelLimits` — 700 × 500 мм, проверка через `validatePanelSize`
5. `layout` — стандартная схема

Шипы и пазы в этом объекте ещё пустые.

## Запуск локально

Из папки приложения:

```bash
cd fanera-box-constructor
python3 -m http.server 4173
```

Открыть http://127.0.0.1:4173/

Модули не работают по `file://`. Нужен любой статический сервер.

Тесты, без дополнительных библиотек:

```bash
cd fanera-box-constructor
node --test tests/*.test.js
```

Из корня репозитория: `npm test`.

## GitHub Pages

Приложение не вызывает API GitHub Pages.

Классические Pages публикуют корень репозитория или папку `/docs`. Эта страница лежит в `fanera-box-constructor`. Чтобы выложить именно её, достаточно GitHub Action, который загружает эту папку как артефакт Pages. Логика конструктора от способа публикации не зависит.
